# DevOps Engineering Journey

This repository documents my practical journey in DevOps, Cloud, Automation, and Infrastructure Engineering.

1. **Prepare Host Environment:** Verify system requirements (minimum 4GB RAM, 10GB disk space) and ensure the operating system (macOS, Linux, or WSL2 on Windows) is updated. 

2. **Establish Version Control:** Install and configure Git, ensuring integration with platforms     like GitHub or GitLab. Install `Visual Studio Code` 

3. **Integrate AI Capabilities:** (Optional/Advanced) Explore the installation of AI-assisted tools such as GitHub Copilot, Amazon Q, Gemini CLI, CodexCLI or LocalStack to enable AI-powered DevOps workflows.

4. **Install Containerization Tools:** Install and configure `Docker` and `Docker Compose` to provide the foundation for containerized applications.

5. **Set Up Kubernetes Tooling:** Install `Minikube` for lightweight local Kubernetes orchestration, install and configure `kubectl` for cluster interaction, and `Helm` for package management.

6. **Configure Cloud and Language Runtimes:** Install major Cloud CLIs (AWS & Azure), `Node.js` for backend development, and `jq` for JSON processing.

7. **Deploy Infrastructure & Configuration Tools:** Install `Terraform` for Infrastructure as Code (IaC) and `Ansible` for automated configuration management.

8. **Verification and Security:** Run verification scripts to ensure all tools are correctly installed and check for proper permission settings.
